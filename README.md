# Product Performance & Inventory Optimization

## Project Overview

This project analyzes product sales, inventory, store performance, and customer data to identify business opportunities and improve inventory management.

The project uses **Python, SQL Server, Excel, and Power BI** to perform data cleaning, analysis, visualization, and business reporting.

## Business Objective

* Identify top-performing products and categories
* Analyze sales and revenue trends
* Identify slow-moving and overstocked inventory
* Analyze inventory value and stock status
* Compare store performance
* Build an interactive Power BI dashboard
* Reduce manual reporting effort through dashboard-based analysis

## 🛠️ Tools & Technologies

* **Python** — Pandas, NumPy, Matplotlib, Seaborn
* **SQL Server** — Data analysis and business queries
* **Excel** — Pivot tables and exploratory analysis
* **Power BI** — Interactive dashboard and KPI reporting
